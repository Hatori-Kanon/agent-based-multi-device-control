怎么用（简版）

  1. 标准 HRS：保持默认 heart_rate / heart_rate_measurement，直接连接。
  2. 厂商私有通道（nRF Connect 里发现的 128-bit / 0xFFF0 类服务）： 勾“原始模式”，把服务/特征 UUID 填进上面两栏，并把该服务 UUID 加进 optionalServices（逗号分隔），再连接。
  3. 停止或设备断连后会自动下载；若浏览器拦截自动下载，点按钮手动下载。文件名带本地时间戳。
  4. 下载的 notifications.jsonl 一行一条，可直接和 hw9cap.py 的产出合并统计； meta.json 是设备/环境片段（序列号已脱敏），可合并进测试目录的 meta.json。
  5. 本页不发起扫描、不写磁盘、不联网；记录只在内存中，刷新即丢失。

注意事项

  1. Web Bluetooth 需要 localhost 或 HTTPS；直接双击打开 file:// 不可用。
  2. 同一时刻只能有一个中心设备连接 HW9：抓包时关掉手机 CooSpo App、别开第二台手机。
  3. Windows 已配对有时反而让 Web Bluetooth 看不到设备；先移除配对再试（计划附录 C）。
  4. 浏览器不能枚举未知服务；这里只订阅你填的服务/特征。全量枚举用 nRF Connect 或 hw9cap.py gatt。
  5. 健康数据只存本地；本页自动把序列号记为“（脱敏）”，device.id 是浏览器按 origin 生成的标识（不是 MAC）。
